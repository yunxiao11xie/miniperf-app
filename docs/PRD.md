# PRD — MiniPerf App（桌面硬件监控独立程序）

> 版本：v1（2026-10-31，SoPro 四步流程首轮对齐）
> 原则：只写做什么，不写怎么做。每条标注【已定】【建议】【待定】。

## 1. 一句话定位

Redmi Book Pro 14 2026（Core Ultra + NPU）上的** Fluent 风格桌面硬件监控独立程序**：
悬浮卡片常驻 + 一键展开全功能面板 + 精致托盘，双击桌面图标即用。

## 2. 用户和场景

- 用户：机器所有者（开发者，多窗口重度用户，对美观与简洁敏感）
- 场景 A：日常余光瞄一眼负载（迷你悬浮条）
- 场景 B：卡顿排查：展开面板看温度/频率/Top 进程定位元凶
- 场景 C：下载/跑 AI 时看网速与 NPU 动态

## 3. 平台

Windows 11 独立桌面程序（WPF），不依赖 Rainmeter。【已定】

## 4. 核心流程

双击桌面图标 → 迷你悬浮条出现（常驻）→ 悬停/点击展开全功能面板 →
面板里看详情与 Top 进程 → 收起回迷你条；托盘图标常驻可开关主窗口。【已定】

## 5. 功能分级

### P0（首版必须）

| # | 功能 |
|---|------|
| P0-1 | 迷你悬浮条：CPU/GPU/NPU/内存/网速·下行/上行 实时数值，可拖动、可置顶、透明度可调、记住位置 |
| P0-2 | 展开面板：全部指标大视图 + CPU/GPU/NPU/内存/网速 实时曲线图（60s 窗口） |
| P0-3 | 数据口径与任务管理器一致（NPU 走 Neural 引擎） |
| P0-4 | 精致托盘图标：实时显示 CPU 百分比数字，右键菜单仅「显示面板 / 退出」，双击开面板 |
| P0-5 | Fluent 亚克力视觉：半透明、圆角、随系统明暗自动切换 |
| P0-6 | 桌面快捷方式双击启动；重复启动时唤起已有实例（不重复开） |
| P0-7 | 阈值变色（≥55% 黄 / ≥85% 红）贯穿迷你条/面板/托盘 |

### P1（首版尽量）

- P1-a 磁盘活动（读写速率 + 活动百分比）
- P1-b 温度与频率（CPU/GPU/NPU，LibreHardwareMonitor 库）
- P1-c Top 进程：面板中点击 CPU/内存指标展开该维度占用前 5 进程

### P2（远期）

- 开机自启（设置开关）、指标历史落盘、开机时间显示、深浅主题手动覆盖

## 6. 首版不做什么

- 不做进程管理（结束任务等，只看不杀）
- 不做配置界面 GUI（首版用快捷键+右键菜单+配置文件）
- 不做多语言（中文界面）
- 不做性能基准测试类功能

## 7. 验收场景（每个 P0 一条）

| P0 | 场景 | 通过标准 |
|----|------|---------|
| P0-1 | 桌面双击图标 | 迷你条出现于右上角；重启程序回到上次位置 |
| P0-2 | 点击迷你条 | 展开面板六指标+曲线滚动流畅（≥1fps 刷新、CPU 占用 <1.5%） |
| P0-3 | 与任务管理器同刻对比 | CPU/内存/NPU 差异 ≤5 个百分点 |
| P0-4 | 观察托盘 | 图标数字随 CPU 变化；右键仅 2 项 |
| P0-5 | 系统切换深/浅色 | 面板自动跟随 |
| P0-6 | 双击图标两次 | 只有一个实例，第二次唤起面板 |
| P0-7 | 跑 CPU 压测 | 迷你条/面板/托盘同步变黄变红 |

## 8. 待定事项

- 【待定】开机自启默认开还是默认关 → 建议默认关，设置里可开（P2）
- 【建议】迷你条默认指标顺序：CPU 内存 | GPU NPU | 网速（三段式）
- 【已定】托盘图标内容 = CPU 百分比（内存作备选，后续可设）
- 【已定】时间目标：中项目 10 小时档（首版含 P1）
