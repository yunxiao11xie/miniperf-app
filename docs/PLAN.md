# PLAN.md — 首版开发规划（v1.0.0）

> 时间目标：中项目 10 小时档（实际预计 4-5 小时）。段间无文件冲突可顺序执行。

## 段 1：可运行骨架（迷你条 + CPU/内存）

- src/Program.cs + MetricsCollector（先只采 CPU/RAM）+ MiniBarWindow（亚克力、
  拖动、置顶）+ build.ps1 + settings（位置记忆）
- 验收：build\MiniPerfApp.exe 双击启动，右上角出现迷你条，CPU/RAM 实时且与
  任务管理器 ±5pp；拖动后重启位置保持
- 预计：60 分钟

## 段 2：数据面补全（GPU/NPU/网速/磁盘）

- GPU Engine 实例缓存管理 + Neural 分组 + 网速全实例求和 + 磁盘
- 迷你条六段全部点亮
- 验收：NPU 跑 AI 应用时变化；网速下载大文件时与浏览器下载速率同量级
- 预计：45 分钟

## 段 3：展开面板

- PanelWindow（八格网格 + 双曲线 ChartControl + Top 进程两 Tab）
- MiniBar 点击展开/收起（面板定位迷你条正下方）；失焦收起
- 验收：展开收起动画顺滑；Top1 进程与任务管理器排序一致
- 预计：75 分钟

## 段 4：托盘 + 交付面

- TrayService（方案C图标：数字+底部进度条，GDI+ 16×16）+ 右键(显示面板/退出)
- 桌面快捷方式自动创建（首次运行）+ Mutex 单实例（二次启动唤起）
- 阈值变色贯穿三处 UI
- 验收：桌面双击启动；重复双击仅唤起；托盘数字随 CPU 变；压测变红
- 预计：60 分钟

## 段 5：大测（全验收清单）

- PRD 第 7 节 7 项 P0 场景逐项过 + 截图存档 + 温度可用性记录
- 预计：30 分钟

## 并行性说明

单 Agent 顺序执行；段 3 与段 4 无依赖理论上可并行，本轮不拆。
