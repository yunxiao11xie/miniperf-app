## 布局常量

### 迷你悬浮条（默认 316×36，圆角 10）
```
[CPU 23%][GPU 0%][NPU 0%][RAM 65%][↓ 3.2][↑ 0.4]   左右 padding 12
```
六段等宽（48px），段间距 0；标签在上（9px 高），数值在下。

### 展开面板（376×560，圆角 14，四个分区）
1. 顶栏（高 44）：标题 MiniPerf + 主题指示点 + 收起按钮「─」
2. 概览网格（2×4，各格 168×64）：八指标标签+大数值
3. 曲线区（高 216）：CPU/内存 两条主曲线 + 图例；点击曲线可切换指标
4. Top 进程区（高 168）：Tab（CPU/内存）+ 前 5 行（名称+占用条+百分比）

### 托盘图标（方案C · 16×16 动态绘制）
- 圆角 4px 半透明白底（浅色 rgba(255,255,255,.35)）+ 细白描边
- 上部大数字（CPU%，9px 粗体）+ 下方 6.5px 灰字 CPU%
- 底部 3px 进度条随值填充（指标蓝；≥85% 整体红调）
- 见 prototype/index.html 方案 C 示意（放大 2 倍）

## 交互规范

| 操作 | 行为 |
|------|------|
| 拖动迷你条 | 移动位置（松手记忆） |
| 滚轮悬停 | 透明度 ±4（40-100%），实时 |
| 单击迷你条 | 展开/收起面板（原地向下展开） |
| 面板外点击 | 收起面板 |
| 托盘双击 | 开关迷你条 |
| Ctrl+滚轮 | 缩放（80%-150%，等比） |

阈值变色：≥55% 数值变警示黄、≥85% 变警示红（含对应曲线线色）。
